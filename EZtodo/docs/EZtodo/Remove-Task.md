# Remove-Task

## SYNOPSIS

Removes the specified task from the task file.

## SYNTAX

### __AllParameterSets

```
Remove-Task [-SourcePath] <string> [-Number] <int> [-PreserveLineNumbers] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION

Removes the specified task from the task file. 

## EXAMPLES

### Example 1 - Remove a task 

```powershell
Remove-Task ./todo.txt 3 
```
